Discover Incredible Tricks with JavaScript

Jahid Hasan October 9, 2023 6 min read

JavaScript has grown a lot in the last few years. Many patterns that used to take five lines of defensive code now fit in one readable expression. In this post I'll share the tricks I reach for almost every day — small things that make code shorter, safer and easier to read.

1. Optional chaining ?.

Reading a deeply nested property used to mean checking every level by hand. Optional chaining stops and returns undefined as soon as it meets null or undefined. 

const user = { profile: { address: null } };

// Before
const city = user && user.profile && user.profile.address && user.profile.address.city;

// After
const city2 = user?.profile?.address?.city; // undefined, no crash

// It works for method calls and array indexes too
user.sayHello?.();          // only called if it exists
const first = user.orders?.[0];

2. Nullish coalescing ??

The classic value || 'default' has a hidden bug: it replaces every falsy value, including 0, '' and false. The ?? operator only falls back when the value is null or undefined. 

const settings = { volume: 0, title: '' };

settings.volume || 50; // 50  ❌ the user chose 0!
settings.volume ?? 50; // 0   ✅

settings.title ?? 'Untitled'; // ''  (kept, because it's not null/undefined)

3. Logical assignment operators

||=, &&= and ??= combine a check and an assignment. They're perfect for setting defaults on objects. 

const options = { retries: 0 };

options.retries ??= 3;     // stays 0
options.timeout ??= 5000;  // set to 5000
options.cache ||= new Map();

4. Destructuring with defaults and renaming

Pull exactly what you need out of an object, rename it, and give it a default — in one line.

function createUser({ name, role: userRole = 'guest', ...rest }) {
  return { name, userRole, rest };
}

createUser({ name: 'Jahid', age: 24 });
// { name: 'Jahid', userRole: 'guest', rest: { age: 24 } }

// Swap two variables without a temp variable
let a = 1, b = 2;
[a, b] = [b, a]; // a = 2, b = 1

5. Remove duplicates with Set

A Set only stores unique values, so turning an array into a Set and back removes duplicates.

const tags = ['js', 'react', 'js', 'node', 'react'];
const unique = [...new Set(tags)]; // ['js', 'react', 'node']

// Unique objects by a key
const users = [{ id: 1 }, { id: 2 }, { id: 1 }];
const byId = [...new Map(users.map((u) => [u.id, u])).values()];

6. Transform objects with Object.entries and Object.fromEntries

Arrays have map and filter; objects don't. Convert to entries, use the array methods, then convert back. 

const prices = { apple: 1.2, mango: 2.5, banana: 0.5 };

const discounted = Object.fromEntries(
  Object.entries(prices)
    .filter(([, price]) => price > 1)
    .map(([fruit, price]) => [fruit, +(price * 0.9).toFixed(2)])
);
// { apple: 1.08, mango: 2.25 }

7. Dynamic (computed) property names

const field = 'email';
const form = { [field]: 'jahidorjahid@gmail.com', [`${field}Verified`]: true };
// { email: 'jahidorjahid@gmail.com', emailVerified: true }

8. Generate arrays quickly

Array.from({ length: 5 }, (_, i) => i * 2); // [0, 2, 4, 6, 8]

[[1, 2], [3, [4, 5]]].flat(Infinity);     // [1, 2, 3, 4, 5]

[1, 2, 3].at(-1);                          // 3 — last item, no length math

9. Readable numbers and quick conversions

const budget = 1_000_000;      // numeric separators — same as 1000000

+'42';           // 42   (string → number)
String(42);      // '42' (number → string)
!!'hello';       // true (any value → boolean)
Math.trunc(4.9); // 4

10. Short-circuit for conditional rendering and calls

Especially handy in React components:

isLoggedIn && showDashboard();

// In JSX
{items.length > 0 && <List items={items} />}

Watch out: {items.length && <List />} renders a literal 0 when the array is empty. Compare explicitly with > 0 as above.

Wrapping up

None of these tricks are magic, but together they remove a lot of noise from everyday code:

  • Use ?. and ?? to handle missing data safely.
  • Use destructuring and logical assignment for clean defaults.
  • Use Set, Map and Object.fromEntries for quick data transforms.
Clean code isn't about being clever — it's about making the next reader's job easy.

Which of these do you use the most? Let me know — and happy coding! 🚀
